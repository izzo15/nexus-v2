# Contributing

1. Branch from `develop`.
2. Use an approved topic-branch prefix.
3. Read all applicable `AGENTS.md` files.
4. Add tests with behavioral changes.
5. Open a PR into `develop`.
6. All required checks must pass.

Release work flows `develop -> release/x.y.z -> main`.
Hotfixes flow `main -> hotfix/* -> main` and are reconciled back into `develop`.
