# Nexus V2

Nexus V2 is the governed successor to Nexus V1.

## Branches
- `main`: stable/release only.
- `develop`: integration for the next release.
- Topic branches: `feat/*`, `fix/*`, `security/*`, `test/*`, `refactor/*`, `docs/*`, `chore/*`.

## Governance
Every committed directory must contain an `AGENTS.md`. CI enforces this before implementation code is accepted.

## Current Phase
Repository bootstrap and Phase 0 baseline/gold-set preparation. No production Nexus V2 agent code should land before the Phase 0 baseline is frozen.
